Andes Trail Club: Site Plan

Site Name

Andes Trail Club

This name represents a club focused on hiking trails in the Andes region of Peru.

Optional domain availability: andestrailclub.org

Site Purpose

The site is a hub for regional hiking. It provides trail recommendations, gear tips, and a membership form.

Scenarios

  • What is the best beginner trail near my city?
  • What gear do I need for a high-altitude hike?

Color Schema

  • Forest green #1f4d3a
    Header, footer, and headings.

  • Cream #f7f5ef
    Page background and text on dark areas.

  • Amber #c9731a
    Accents and heading underlines.

  • Charcoal #232323
    Paragraph text.

Typography

  • Merriweather (bold): used for the site name and all headings.
  • Open Sans: used for paragraphs, lists, and forms.

Wireframes

Home page layouts for mobile and desktop views.
